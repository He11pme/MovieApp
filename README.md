# MovieApp
## Installation & Setup
The application uses the TMDb API to retrieve movie information.  
To run the app, you need to add an API key to the `local.properties` file.

You can obtain an API key from the official website:  [TMDb API](https://developer.themoviedb.org/docs/getting-started)

Add the following line to `local.properties`:

```
TMDB_API_KEY=your api key
```
